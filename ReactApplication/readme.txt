ShopEase: React eCommerce App
    ShopEase is a user-friendly eCommerce platform built using React, Redux, and Bootstrap. 
    It provides a seamless shopping experience with product browsing, cart management, and 
    user authentication.

Features:
    User Registration and Login
    Product Catalog with price and image details
    Add/Remove items to/from the shopping cart
    Basic form validation for registration and login
    Persistent cart with Redux state management
    Responsive UI using React Bootstrap

Technologies Used:
    React: A JavaScript library for building user interfaces.
    Redux: For state management (cart and product data).
    React Router: For navigation between different pages (Home, Products, Cart, Login, Registration).
    Axios: For making HTTP requests to fetch products.
    Bootstrap: For responsive UI components.
    json-server: For simulating a backend API to store user data.
